# 专色审版台（Spot Color Proof Bench）

浏览器端专色套印审版工具：Vue 3 + TypeScript + WebGL2，无需后端，数据存 IndexedDB。

## 启动

```bash
pnpm install
pnpm dev      # 本地开发
pnpm build    # 类型检查 + 生产构建
```

## 路由

| 路由 | 职责 |
| --- | --- |
| /library | 印件库：内置双色礼盒（固定种子重建）、浏览器存档、JSON 导入、印件复制 |
| /separation | 分色：色版增删改色、墨序、网点角、套准偏移、对象图层与文字曲线编辑 |
| /overprint | 套印：叠印/挖空、自动陷印、尖角限幅、纸色、遮盖率、漏白定位、分版对照 |
| /delivery | 交付：SVG 分版导出、PNG 合成出图、自动回读逐像素校验、工程导出 |

## 印刷模型

每个色版光栅化为一张 RGBA 纹理（stencil even-odd 填充，天然保留字孔）：

- R：覆盖率（对象不透明度）
- G：挖空掩膜，仅非叠印对象写入
- B：陷印外扩带，仅沿外轮廓三角带生成，字孔不描边
- A：字孔掩膜

合成 shader 按墨序逐版处理：

- 挖空（overprint=false）：掩膜命中且非字孔处，下层结果重置为纸色
- 叠印（overprint=true）：无挖空掩膜，保留下层并叠本版墨色
- 陷印：外扩带补本版墨色，字孔掩膜内不补，不堵字孔
- 尖角限幅：CPU 描边时 miter 长度超 miterLimit 自动降级斜切
- 套准偏移：纹理采样平移；漏白定位：膨胀邻域检测无墨缝隙并红色警示
- 网点：按各色版角度生成旋转圆网屏

## 导出一致性

SVG 版片与 WebGL 预览共用同一份对象几何与陷印三角带；PNG 由同一套离屏
纹理出图，导出后自动解码回读并与实时渲染逐像素比对，输出差异热图与报告。

## 字体

public/fonts 内置 Arial 与 SimHei（本地 TTF），opentype.js 离线将文字扁平化为
三次贝塞尔折线，字孔按轮廓方向自动识别。
